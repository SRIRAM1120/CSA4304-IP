INTERNET PROGRAMMING LAB — FORMATTED SOURCE CODE

This ZIP contains 47 experiment folders. Each experiment has its own index.html, style.css, and script.js.

HOW TO RUN
1. Extract this ZIP to a folder.
2. Open the extracted folder and open an experiment folder, for example Experiment_02_Hotel_Booking.
3. Double-click index.html to run the website in your browser.
4. To view/edit code, open the experiment folder in VS Code. HTML, CSS, and JavaScript are in separate files and formatted across multiple lines.
5. In VS Code, use Shift+Alt+F (Windows) to format a file if you edit it later.

IMPORTANT
These are front-end lab demonstrations. Data is local to the page; there is no real payment gateway, live booking provider, external database, or real authentication unless separately connected to a backend. Internet may be needed for remote fonts if a page uses them.

Start page: open index.html in the main folder to choose an experiment.
